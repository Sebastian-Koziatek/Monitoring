Grafana oferuje dwa sposoby zarządzania pluginami: przez interfejs webowy (UI) oraz przez narzędzie wiersza poleceń Grafana CLI. Oba wymagają restartu serwera Grafana po każdej zmianie.

---

## Instalacja przez interfejs webowy (UI)

Wymaga dostępu serwera Grafany do internetu.

1. Zaloguj się jako administrator.
2. Przejdź do **Administration > Plugins**.
3. Kliknij **Browse** lub wyszukaj plugin w polu wyszukiwania.
4. Kliknij wybrany plugin, następnie **Install**.
5. Zrestartuj Grafanę — kliknij **Restart required** lub uruchom ręcznie:
   ```bash
   sudo systemctl restart grafana-server
   ```

---

## Instalacja przez Grafana CLI

**Podstawowa instalacja:**

```bash
sudo grafana cli plugins install <plugin-id>
sudo systemctl restart grafana-server
```

**Przykład — instalacja Zabbix:**

```bash
sudo grafana cli plugins install alexanderzobnin-zabbix-app
sudo systemctl restart grafana-server
```

Pełna dokumentacja komend CLI znajduje się w sekcji **XIV. Grafana-CLI**.

---

## Aktywacja pluginu typu App

Pluginy aplikacji (App plugins) wymagają aktywacji po instalacji:

1. Przejdź do **Administration > Plugins**.
2. Wyszukaj zainstalowany plugin.
3. Kliknij plugin i wybierz **Enable**.
4. Plugin pojawi się w menu bocznym lub będzie dostępny jako źródło danych.

> Pluginy typu **Data Source** i **Panel** są dostępne od razu po restarcie — nie wymagają aktywacji.

---

## Aktualizacja pluginów

**Przez UI:**
1. **Administration > Plugins** — pluginy z dostępną aktualizacją wyświetlają badge z wersją.
2. Kliknij plugin i wybierz **Update**.
3. Zrestartuj Grafanę.

**Przez CLI:**

```bash
# Aktualizacja konkretnego pluginu
sudo grafana cli plugins update <plugin-id>

# Aktualizacja wszystkich pluginów
sudo grafana cli plugins update-all

sudo systemctl restart grafana-server
```

---

## Wyłączanie i usuwanie pluginów

**Wyłączanie (tylko App plugins):**
1. **Administration > Plugins** > wybierz plugin.
2. Kliknij **Disable** — plugin pozostaje zainstalowany, ale jest nieaktywny.

**Usuwanie przez CLI:**

```bash
sudo grafana cli plugins remove <plugin-id>
sudo systemctl restart grafana-server
```

## Instalacja w środowisku bez dostępu do internetu (air-gapped)

W środowiskach izolowanych:

1. Pobierz plik ZIP pluginu z grafana.com/grafana/plugins na maszynie z dostępem do internetu.
2. Skopiuj plik ZIP na serwer Grafany.
3. Zainstaluj z pliku lokalnego:

```bash
sudo grafana cli \
  --pluginUrl file:///tmp/alexanderzobnin-zabbix-app-4.4.0.zip \
  plugins install alexanderzobnin-zabbix-app
sudo systemctl restart grafana-server
```

Alternatywnie, rozpakuj ZIP bezpośrednio do katalogu pluginów:

```bash
sudo unzip plugin.zip -d /var/lib/grafana/plugins/
sudo chown -R grafana:grafana /var/lib/grafana/plugins/
sudo systemctl restart grafana-server
```

## Weryfikacja instalacji

Po restarcie sprawdź, czy plugin jest widoczny:

```bash
# Lista zainstalowanych pluginów
grafana cli plugins ls
```

W UI: **Administration > Plugins** — plugin powinien pojawić się na liście.

Sprawdź logi pod kątem błędów ładowania:

```bash
sudo journalctl -u grafana-server -n 100 | grep -i plugin
```

## Dobre praktyki

- **Restartuj po każdej zmianie** — bez restartu `grafana-server` zmiany w pluginach nie są widoczne.
- **Sprawdzaj kompatybilność** — na stronie pluginu zawsze widoczna jest informacja o wspieranych wersjach Grafany.
- **Testuj w staging** — przed wdrożeniem w produkcji testuj nowe i zaktualizowane pluginy.
- **Dokumentuj instalacje** — przechowuj listę zainstalowanych pluginów (`grafana cli plugins ls`) w repozytorium.
- **Pluginy niepodpisane** — jeśli plugin jest niepodpisany, dodaj wyjątek do `grafana.ini`:
  ```ini
  [plugins]
  allow_loading_unsigned_plugins = <plugin-id>
  ```

---

## Podsumowanie

Pluginy można instalować przez **UI** (Administration > Plugins) lub przez **Grafana CLI**. Każda zmiana wymaga restartu serwera. Pluginy App wymagają dodatkowej aktywacji w UI. W środowiskach bez internetu możliwa jest instalacja z pliku ZIP.
