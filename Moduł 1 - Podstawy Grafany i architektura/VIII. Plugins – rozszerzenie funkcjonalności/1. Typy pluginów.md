Pluginy w Grafanie to rozszerzenia, które dodają nowe możliwości do platformy: nowe źródła danych, typy wizualizacji lub kompletne aplikacje monitorujące. Dzięki pluginom Grafana może współpracować z setkami różnych systemów i narzędzi.

## Architektura pluginów

Każdy plugin to osobny katalog w `/var/lib/grafana/plugins/` zawierający:
- plik manifestu `plugin.json` z metadanymi,
- kod backend (Go, opcjonalny) i/lub frontend (TypeScript/React),
- dokumentację i zasoby graficzne.

Pluginy mogą pochodzić z:
- **Grafana Plugin Catalog** — oficjalne i community pluginy,
- **prywatnych repozytoriów** — wewnętrzne pluginy organizacji,
- **własnego kodu** — możliwość tworzenia własnych pluginów.

## Typy pluginów

### 1. Data Source (Źródło danych)

Pluginy źródeł danych umożliwiają Grafanie łączenie się z systemami, które nie mają wbudowanej obsługi.

**Charakterystyka:**
- Implementują protokół komunikacji ze źródłem danych.
- Dostarczają dedykowany query editor w UI Grafany.
- Mogą działać w trybie frontend (JavaScript) lub backend (Go + JavaScript).

**Przykłady:**

| Plugin | System |
|--------|--------|
| `alexanderzobnin-zabbix-app` | Zabbix |
| `grafana-postgresql-datasource` | PostgreSQL (wbudowany) |
| `grafana-prometheus-datasource` | Prometheus (wbudowany) |
| `grafana-elasticsearch-datasource` | Elasticsearch (wbudowany) |
| `grafana-influxdb-datasource` | InfluxDB (wbudowany) |
| `grafana-mysql-datasource` | MySQL (wbudowany) |
| `grafana-azure-monitor-datasource` | Azure Monitor |
| `marcusolsson-json-datasource` | Dowolne API REST (JSON) |
| `marcusolsson-csv-datasource` | Pliki CSV |

> Źródła danych wbudowane (PostgreSQL, Prometheus, InfluxDB, MySQL, Elasticsearch) nie wymagają instalacji — są częścią Grafany OSS.

### 2. Panel (Wizualizacja)

Pluginy paneli dodają nowe typy wykresów i widgetów do dashboardów.

**Charakterystyka:**
- Renderują dane jako wizualizacje w panelach dashboardu.
- Wiele typów wizualizacji jest wbudowanych w Grafanę (Time series, Bar chart, Gauge, Table, Heatmap, Geomap i inne).
- Pluginy rozszerzają tę listę o specjalizowane wizualizacje.

**Przykłady:**

| Plugin | Opis |
|--------|------|
| `grafana-clock-panel` | Zegar — aktualny czas i data |
| `grafana-worldmap-panel` | Mapa świata z danymi geograficznymi |
| `natel-discrete-panel` | Wykres dyskretny (statusy i stany) |
| `marcusolsson-gantt-panel` | Wykres Gantta |
| `ae3e-plotly-panel` | Zaawansowane wykresy Plotly.js |

### 3. App (Aplikacja)

Pluginy aplikacji to kompleksowe rozszerzenia łączące wiele źródeł danych, paneli i dedykowanych stron UI.

**Charakterystyka:**
- Zawierają zintegrowany interfejs użytkownika (własne strony, menu).
- Często łączą w sobie data source plugin i panel plugin.
- Wymagają aktywacji w **Administration > Plugins** po instalacji.

**Przykłady:**

| Plugin | Opis |
|--------|------|
| `alexanderzobnin-zabbix-app` | Zabbix — monitoring, triggery, historia metryk |
| `grafana-oncall-app` | On-call management i eskalacje |
| `grafana-incident-app` | Zarządzanie incydentami |
| `grafana-k8s-app` | Monitoring Kubernetes |

## Grafana Plugin Catalog

Oficjalny katalog pluginów zawiera ponad 350 rozszerzeń i jest dostępny pod adresem grafana.com/grafana/plugins.

Katalog oferuje:
- filtrowanie po typie (Data source, Panel, App) i źródle (Core, Enterprise, Community),
- oceny, liczby pobrań i informacje o kompatybilności z wersjami Grafany,
- linki do dokumentacji i kodu źródłowego.

### Jak korzystać z katalogu?

1. Znajdź plugin na stronie katalogu.
2. Skopiuj **Plugin ID** (np. `alexanderzobnin-zabbix-app`).
3. Zainstaluj przez CLI: `sudo grafana cli plugins install <plugin-id>`.
4. Lub zainstaluj przez UI: **Administration > Plugins > Browse**.

## Pluginy wbudowane vs. zewnętrzne

| Cecha | Wbudowane | Zewnętrzne (pluginy) |
|-------|-----------|----------------------|
| Instalacja | Nie wymagana | `grafana cli plugins install` |
| Wsparcie | Grafana Labs | Autor pluginu / community |
| Audyt bezpieczeństwa | Tak (Grafana Labs) | Zależy od autora |
| Aktualizacje | Razem z Grafaną | `grafana cli plugins update` |
| Wymagany restart | Nie | Tak |

## Podpisywanie pluginów

Od Grafany 7.4 pluginy muszą być podpisane, aby działać bez ostrzeżeń. Kategorie podpisów:

| Kategoria | Opis |
|-----------|------|
| **Grafana** | Oficjalny plugin audytowany przez Grafana Labs |
| **Commercial** | Plugin komercyjny audytowany przez Grafana Labs |
| **Community** | Plugin podpisany przez zewnętrznego autora |
| **Unsigned** | Plugin niepodpisany — wymaga ręcznego zezwolenia |

Aby zezwolić na ładowanie niepodpisanego pluginu, dodaj do `/etc/grafana/grafana.ini`:

```ini
[plugins]
allow_loading_unsigned_plugins = my-plugin-id
```

---

## Podsumowanie

Grafana obsługuje trzy typy pluginów: **Data Source** (źródła danych), **Panel** (wizualizacje) i **App** (aplikacje). Większość popularnych systemów monitoringu jest obsługiwana przez wbudowane źródła danych. Zewnętrzne pluginy (np. Zabbix) instaluje się przez Grafana CLI lub UI i wymagają restartu serwera. Pluginy App wymagają dodatkowo aktywacji w interfejsie.
