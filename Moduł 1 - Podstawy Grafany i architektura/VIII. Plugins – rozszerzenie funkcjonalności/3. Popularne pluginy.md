Zestawienie najczęściej używanych pluginów Grafany pogrupowanych według kategorii. Wszystkie dostępne są w oficjalnym katalogu grafana.com/grafana/plugins.

---

## Źródła danych (Data Source plugins)

### Zabbix

- **Plugin ID:** `alexanderzobnin-zabbix-app`
- **Typ:** App (zawiera data source + panel)
- **Opis:** Integracja z Zabbixem — pobieranie metryk, historii, danych z triggerów i grup hostów. Jeden z najpopularniejszych community pluginów dla Grafany.
- **Instalacja:**
  ```bash
  sudo grafana cli plugins install alexanderzobnin-zabbix-app
  ```
- **Wymagania:** Aktywacja w **Administration > Plugins** po instalacji. Zabbix 5.4+ — zalecana autoryzacja przez API token.

### Azure Monitor

- **Plugin ID:** `grafana-azure-monitor-datasource`
- **Typ:** Data Source
- **Opis:** Łączy Grafanę z Azure Monitor, Azure Log Analytics i Application Insights. Umożliwia wizualizację metryk infrastruktury i aplikacji w chmurze Azure.

### Google Sheets

- **Plugin ID:** `grafana-googlesheets-datasource`
- **Typ:** Data Source
- **Opis:** Pozwala używać arkuszy Google Sheets jako źródła danych. Przydatne do dashboardów opartych na ręcznie aktualizowanych danych biznesowych.

### JSON API

- **Plugin ID:** `marcusolsson-json-datasource`
- **Typ:** Data Source
- **Opis:** Pobiera dane z dowolnego API REST zwracającego JSON. Umożliwia integrację z systemami, które nie mają dedykowanego pluginu.

### CSV

- **Plugin ID:** `marcusolsson-csv-datasource`
- **Typ:** Data Source
- **Opis:** Wczytuje dane z plików CSV (lokalnych lub dostępnych przez HTTP/HTTPS). Przydatne do jednorazowych analiz lub importu danych historycznych.

## Wizualizacje (Panel plugins)

### Clock

- **Plugin ID:** `grafana-clock-panel`
- **Typ:** Panel
- **Opis:** Wyświetla aktualny czas i datę w wybranej strefie czasowej. Często stosowany na dashboardach NOC i centrum monitoringu.
- **Instalacja:**
  ```bash
  sudo grafana cli plugins install grafana-clock-panel
  ```

### Worldmap Panel

- **Plugin ID:** `grafana-worldmap-panel`
- **Typ:** Panel
- **Opis:** Mapa świata z możliwością kolorowania krajów lub wyświetlania punktów na podstawie danych geograficznych. Przydatny do wizualizacji ruchu sieciowego, lokalizacji klientów lub zdarzeń.
- **Instalacja:**
  ```bash
  sudo grafana cli plugins install grafana-worldmap-panel
  ```

### Discrete Panel

- **Plugin ID:** `natel-discrete-panel`
- **Typ:** Panel
- **Opis:** Wyświetla dane dyskretne (stany, statusy) jako kolorowe paski na osi czasu. Alternatywa dla wbudowanego State Timeline z bardziej elastyczną konfiguracją.

### Gantt

- **Plugin ID:** `marcusolsson-gantt-panel`
- **Typ:** Panel
- **Opis:** Wykres Gantta — wizualizacja zadań, procesów i harmonogramów w czasie. Przydatny do prezentacji okien serwisowych lub etapów wdrożeń.

### Plotly

- **Plugin ID:** `ae3e-plotly-panel`
- **Typ:** Panel
- **Opis:** Zaawansowane wykresy oparte na bibliotece Plotly.js: wykresy 3D, scatter, bąbelkowe, mapy ciepła. Dla użytkowników potrzebujących niestandardowych wizualizacji.

## Aplikacje (App plugins)

### Grafana OnCall

- **Plugin ID:** `grafana-oncall-app`
- **Typ:** App
- **Opis:** Zarządzanie dyżurami (on-call scheduling) i eskalacjami alertów. Integruje się z PagerDuty, Opsgenie, Slack i innymi narzędziami incydentów.

### Grafana Incident

- **Plugin ID:** `grafana-incident-app`
- **Typ:** App
- **Opis:** Zarządzanie incydentami bezpośrednio z Grafany — tworzenie, śledzenie i retrospektywy incydentów.

## Jak wybrać plugin?

Przed instalacją zewnętrznego pluginu sprawdź:

1. **Datę ostatniej aktualizacji** — plugin nieaktualizowany od ponad roku może nie być kompatybilny z nową wersją Grafany.
2. **Liczbę pobrań i oceny** — popularność świadczy o dojrzałości i wsparciu community.
3. **Typ podpisu** — pluginy oznaczone jako `Grafana` lub `Commercial` są audytowane; `Community` to pluginy zewnętrznych autorów.
4. **Kompatybilność** — na stronie pluginu widoczne są minimalna i maksymalna obsługiwana wersja Grafany.
