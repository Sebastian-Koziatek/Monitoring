# Elasticsearch

![Elasticsearch](/grafiki/m1-018-elasticsearch.png)

## Wprowadzenie do Elasticsearch

**Elasticsearch** to rozproszona wyszukiwarka i baza danych NoSQL, zoptymalizowana do przechowywania i wyszukiwania danych tekstowych oraz analizy danych szeregów czasowych. Jest częścią zestawu **Elastic Stack (ELK)**, który obejmuje również:
- **Logstash** — zbieranie i przetwarzanie danych (filtrowanie, parsowanie),
- **Beats** (Filebeat, Metricbeat) — lekkie agenty zbierające logi i metryki,
- **Kibana** — natywny interfejs wizualizacji Elastic Stack (Grafana może go zastąpić lub uzupełnić).

### Kluczowe cechy Elasticsearch:

- Szybkie wyszukiwanie pełnotekstowe i filtrowanie danych.
- Obsługa ogromnych wolumenów danych z możliwością skalowania poziomego.
- Wbudowana obsługa agregacji danych i analiz czasowych.

## Grafana i Elasticsearch

Grafana umożliwia wizualizację danych z Elasticsearch, co czyni go przydatnym narzędziem do monitorowania aplikacji, analizy logów i danych metrycznych w czasie rzeczywistym.

> **OpenSearch:** Grafana obsługuje również **OpenSearch** (fork Elasticsearch rozwijany przez AWS) jako osobne źródło danych. Jeśli Twoja organizacja używa OpenSearch zamiast Elasticsearch, wybierz typ źródła danych **OpenSearch** zamiast **Elasticsearch** w konfiguracji Grafany.

## Instalacja i konfiguracja Elasticsearch

### Instalacja Elasticsearch (na przykładzie Ubuntu 24.04)

1. Dodaj klucz GPG i repozytorium Elastic:
   ```bash
   wget -qO - https://artifacts.elastic.co/GPG-KEY-elasticsearch | \
     sudo gpg --dearmor -o /usr/share/keyrings/elasticsearch-keyring.gpg

   echo "deb [signed-by=/usr/share/keyrings/elasticsearch-keyring.gpg] \
     https://artifacts.elastic.co/packages/8.x/apt stable main" | \
     sudo tee /etc/apt/sources.list.d/elastic-8.x.list
   ```
2. Zainstaluj Elasticsearch:
   ```bash
   sudo apt update
   sudo apt install elasticsearch
   ```
3. Skonfiguruj Elasticsearch w pliku `/etc/elasticsearch/elasticsearch.yml`:
   ```yaml
   network.host: localhost
   http.port: 9200
   ```
4. Uruchom i włącz Elasticsearch:
   ```bash
   sudo systemctl start elasticsearch
   sudo systemctl enable elasticsearch
   ```
5. Sprawdź działanie:
   ```bash
   curl -X GET "localhost:9200/_cluster/health?pretty"
   ```

## Konfiguracja Grafany z Elasticsearch

1. Zaloguj się do interfejsu webowego Grafany.
2. Przejdź do sekcji **Connections > Data Sources**.
3. Kliknij przycisk **Add data source** i wybierz **Elasticsearch**.
4. Wypełnij pola:
   - **URL**: `http://localhost:9200`
   - **Index name**: `logstash-*` (lub inny prefiks, jeśli dane są indeksowane inaczej).
   - **Time field name**: `@timestamp`
5. Kliknij **Save & Test**, aby upewnić się, że Grafana poprawnie połączyła się z Elasticsearch.

## Tworzenie Dashboardów

### Tworzenie panelu z wykorzystaniem query buildera

Grafana posiada wbudowany **query builder** dla Elasticsearch — nie musisz pisać surowego Query DSL w JSON.

1. Przejdź do sekcji **Dashboards > New Dashboard** w Grafanie.
2. Dodaj nowy panel (**Add a new panel**).
3. Wybierz Elasticsearch jako źródło danych.
4. W sekcji **Query** skorzystaj z query buildera:
   - **Index** — wybierz indeks (np. `logstash-*`).
   - **Metric** — wybierz agregację (np. `Count`, `Average`, `Sum`).
   - **Group by** — pogrupuj dane według czasu (`Date Histogram`) i opcjonalnie według pola (np. `host.keyword`).
   - **Filter** — opcjonalnie ogranicz wyniki (np. `log.level: error`).
5. Dostosuj wizualizację (np. wykres liniowy, tabela).
6. Zapisz panel i dodaj go do dashboardu.

> **Zaawansowane zapytania:** Jeśli query builder nie wystarczy, możesz przełączyć się na tryb **Raw** i wpisać Query DSL bezpośrednio. Jest to jednak zalecane tylko dla zaawansowanych użytkowników.

## Najlepsze praktyki

- **Optymalizacja zapytań:** Używaj agregacji i filtrów w query builderze, aby minimalizować ilość przetwarzanych danych.
- **Indeksowanie danych:** Upewnij się, że dane są prawidłowo indeksowane, z odpowiednio skonfigurowanym polem czasowym (`@timestamp`).
- **Wydajność:** Regularnie monitoruj stan klastra Elasticsearch i stosuj shardowanie oraz replikację zgodnie z wymaganiami.

## Podsumowanie

Elasticsearch i Grafana to potężne narzędzia do analizy i wizualizacji danych. Wbudowany query builder Grafany znacznie upraszcza pracę z danymi Elasticsearch bez konieczności znajomości Query DSL. Dla środowisk używających OpenSearch — Grafana oferuje dedykowane źródło danych zapewniające pełną kompatybilność.
